# 字幕词库示例

这是公开的格式示例，不会默认作为当前视频的词库。姓名为虚构，使用前替换成自己的内容。
将本文件复制为 `<skill-dir>/local/glossary.md`，或在任务中明确提供另一份词库路径。
无需安装额外依赖；由 Agent 在转录后的校对阶段读取，不会自动传给语音识别模型。

## 姓名与专名

| 标准写法 | 已知误识别／别名 | 使用范围 |
| --- | --- | --- |
| 林晓 | 林小 | 虚构人物示例；仅在确认指向该人时使用 |
| Claude Code | 克劳德 code | 确认在讨论该编程工具时使用 |
| MCP | 无 | 技术缩写，结合音频确认，不替换相似发音的其他词 |

## 常用术语

`Codex`、`Claude Code`、`Agent`、`Skill`、`MCP`、`GitHub`、`CLI`、`IDE`

保留与自己领域有关的词，删除无关条目。可以补充产品、人名、项目名、标准大小写，以及已确认的误识别。

## 校对约定

- 词库提供候选写法，不能证明音频说了这个词；不确定时回听，仍无法确认则交给用户核实。
- 只在身份和上下文匹配时修正姓名，不把所有说话人视为同一人。
- 一次性的字幕修改只写回校对 SRT；用户明确要求维护词库时，再更新本机词库。
- 不把本机词库内容写入公开示例、README、提交说明或其他公开材料。

## 本机保存

本仓库的 `.gitignore` 忽略 `skills/shuai-burn-video-subtitles/local/`。通过安装工具复制到其他 Git 项目时，原仓库的忽略规则未必随 Skill 安装；请在目标项目加入对应 `local/` 路径的忽略规则，或将私人词库存放在仓库外并在任务中传入路径。

本机文件不会随重新安装或其他设备自动迁移。替换安装目录前自行备份；需要跨设备使用时自行安全同步。
